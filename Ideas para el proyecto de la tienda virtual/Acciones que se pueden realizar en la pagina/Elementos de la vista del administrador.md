# Elementos que van a ser vistos en la sección de Administrador

En esta parte prácticamente se mantiene todo lo que se tenía previsto en el wireframe anteriormente creado, un dashboard de administrador, que permite hacer operaciones CRUD, en el que se puede hacer una pequeña estadística de los productos más vendidos, para que se puedan hacer estrategias de ventas.

La nueva integración que se planea hacer con esta parte, mejor dicho, es un apartado con los datos del comprador de un producto, para que se pueda gestionar lo de los pedidos
